# Architecture Documentation

Use this directory for architecture overviews, diagrams, system maps, data-flow notes, and integration-level explanations that are too detailed for governance files.

## Current Status

- No standalone architecture documents have been added yet.
- Current accepted decisions are indexed in [../governance/DECISIONS.md](../governance/DECISIONS.md).
- Future ADR files belong in [../decisions/](../decisions/).
- Reference material lives in [../references/](../references/).

## Guidelines

- Keep architecture documents descriptive, not task-based.
- Link to source reference documents instead of copying long sections.
- Record accepted architectural choices as ADRs when they affect long-term implementation direction.
