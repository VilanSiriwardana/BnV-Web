# Architecture Decision Records

Future standalone ADR files belong in this directory. The current decision index remains at [../governance/DECISIONS.md](../governance/DECISIONS.md).

## Numbering Convention

Use sequential IDs:

- `ADR-0001`
- `ADR-0002`
- `ADR-0003`

Recommended filename format:

```text
ADR-0001-short-kebab-case-title.md
```

## ADR Template

```markdown
# ADR-0000 - Title

- Date:
- Status: Proposed | Accepted | Superseded | Deprecated

## Context

## Decision

## Alternatives

## Consequences

## Related Documents
```
