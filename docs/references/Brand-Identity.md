Brand Identity & Design System Reference v1.0

## Project Status

This document defines the current design direction, visual identity rules, color system, typography system,
logo rules, naming rules, UI style, imagery direction, and Tailwind implementation approach for the
upcoming couple lifestyle ecommerce brand.
The final brand name and logo are not yet locked. They will be decided later using the rules in this
document.
This document should be used as the design reference before preparing:
final brand naming shortlist
logo exploration
Figma design system
homepage UI design
Tailwind global theme setup
ecommerce component library
future brand guidelines

## 1. Brand Vision

The business is not just a normal ecommerce website.
It is a modern couple lifestyle brand focused on:
couple fashion
jewelry
personalized gifts
romantic gift boxes
custom orders
digital love experiences
event and love websites
couple content
memory-based products
future lifestyle collections
The brand should feel emotional, personal, premium, and story-driven.
The original business direction is built around the idea that the relationship, couple content, fashion,
creativity, lifestyle, story, aesthetics, and emotional energy become part of the brand’s marketing engine.

## 15. Color Balance Rule

The palette should approximately follow this visual balance:
UsagePurpose
60%Warm Ivory and light backgrounds
20%Soft Blush and soft surfaces
10%Signature Lavender brand moments
5%Dusty Rose romantic accents
3%Champagne Gold luxury details
2%Strong contrast and structural details
This prevents the website from becoming too purple, too pink, or too decorative.
The overall interface should remain light, breathable, and premium.

## 16. Accessibility Note

Signature Lavender is the main brand color, but it may not always provide enough contrast for all text/
button combinations.

## Therefore:

do not force exact Signature Lavender for every CTA
use darker accessible lavender variations when needed
use Soft Charcoal text on light lavender backgrounds
use white or ivory text only when contrast is verified
generate a full semantic color scale later
separate brand colors from UI state colors
Brand identity and UI accessibility should work together.

## 20. Typography Rules

## 20.1 Use Only Two Core Fonts

The brand should mainly use:

## Playfair Display

## Inter

Avoid adding many decorative fonts.

## 20.2 Use Display Font Sparingly

Playfair Display should create emotional impact.
Do not use it for:
long product descriptions
cart details
checkout instructions
form-heavy sections
admin dashboard
small mobile labels
20.3 Use Inter for Usability
Inter should handle all functional reading and UI interactions.
This keeps the ecommerce experience clear and easy to use.

## 41. Dark Mode Theme Design Decisions

Dark mode is now included in the design system as a parallel theme. It must preserve the same soft
luxury, romantic, lavender-led identity defined in the light mode, while creating a more cinematic
evening experience.

## Core Decision

Light mode remains the primary brand experience. Dark mode becomes the cinematic evening
version of the same brand. It should feel like midnight lavender, candlelight, premium packaging,
date-night atmosphere, and editorial fashion - not gaming purple, neon romance, or harsh black
luxury.

## Midnight Lavender Luxury

The dark theme should still feel modern, romantic, premium, cinematic, minimal, and emotionally
warm. It should support ecommerce, fashion, jewelry, gifts, custom orders, and love website

## 41.3 Why These Dark Mode Colors Work

Midnight Aubergine - #17121D
This replaces pure black. It keeps the interface deep and cinematic while preserving a romantic
lavender undertone. Pure black is avoided because it can feel harsh, cheap, and tiring.
Deep Plum Surface - #241B2E
Used for cards, sections, navbar, drawers, and footer areas. It creates layering without introducing
cold grey.
Signature Lavender - #C8B6E2
The primary brand color stays the same in both light and dark modes. This keeps the brand
recognizable across themes.
Moon Ivory - #F7F1EA
Used instead of pure white. It keeps text warm, soft, and premium on dark backgrounds.
Candlelight Gold - #D2B16F
A slightly brighter gold is used in dark mode because dark backgrounds absorb warmth. It
preserves the jewelry, packaging, and premium collection feeling.
Smoky Taupe Plum - #4A3A50
Borders must be visible but not harsh. This keeps the UI structured while staying inside the
lavender luxury identity.

MVP behavior: support Light and Dark. Later behavior: add System preference if needed.
