## Buwi & Vila

## Technology Stack & Tools Reference

## Version 1.0 – Initial Engineering Reference

## Purpose

This document establishes the initial technology stack, engineering decisions, and supporting tools
that will be used as the baseline reference for the Buwi & Vila platform. Future architecture,
database, API, UI/UX, SEO, DevOps, and AI documents will build upon this foundation.

## Engineering Philosophy

- SEO-first, performance-first, mobile-first development.
- Modern web standards using TypeScript.
- Scalable architecture without unnecessary complexity.
- Content-driven commerce with premium user experience.
- Developer productivity, maintainability, and future AI readiness.

## Core Technology Stack

Frontend + Backend: Next.js (App Router, Server Components, Route Handlers, Server Actions)
Language: TypeScript
Styling: Tailwind CSS + Global CSS

## Animations: Framer Motion

ORM: Prisma
Database: PostgreSQL

## Validation: Zod

## Authentication: Auth.js

CMS: Sanity

## Media Storage: Cloudinary

Payments: PayHere + KOKO
Hosting: Vercel (Current) + Railway (Future Scaling)

## Local Infrastructure: Docker Compose
